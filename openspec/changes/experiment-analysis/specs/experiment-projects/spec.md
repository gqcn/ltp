## ADDED Requirements

### Requirement: 创建与编辑实验项目

拥有训练中心菜单的会话 MUST 能创建实验项目。必填名称为非空且最长 64 个字符。描述可选，最长 256 个字符。未删除的项目名称 MUST 唯一（大小写不敏感）。创建失败时 MUST 用中文错误写在输入域旁。编辑 MUST 允许修改名称与描述；`default` Seed 项目名称 MUST 只读。系统 MUST 内置一条标识为`default`、显示名为「默认项目」的 Seed 项目，供未指定项目的任务自动关联。侧栏项目列表 MUST NOT 展示编辑或删除按钮；选中某项目后，这些操作 MUST 出现在页面右侧选中区域。侧栏项目项 MUST 只展示名称与实验数量，MUST NOT 展示描述；描述 MUST 只出现在右侧选中区域。

#### Scenario: 创建项目后出现在侧栏

- **WHEN** 算法工程师填写名称`slm-7b-pretrain`并确认创建
- **THEN** 项目侧栏出现该项目，且成为当前选中项

#### Scenario: 项目描述只在选中后可见

- **WHEN** 用户创建或编辑项目并填写描述
- **THEN** 侧栏该项目不展示描述；选中该项目后主区域展示描述

#### Scenario: 重名被拦截

- **WHEN** 已存在活跃项目`slm-7b-pretrain`，用户再次用该名称创建
- **THEN** 输入域旁展示中文错误，不新增项目

#### Scenario: 选中后可改名

- **WHEN** 用户选中非默认项目并打开编辑
- **THEN** 名称可改，保存后侧栏与右侧标题展示新名称

#### Scenario: 默认项目名称只读

- **WHEN** 用户选中「默认项目」并打开编辑
- **THEN** 名称输入框只读，保存只更新描述

#### Scenario: 操作按钮在右侧

- **WHEN** 用户尚未选中具体项目
- **THEN** 侧栏没有编辑或删除按钮
- **WHEN** 用户选中某个项目
- **THEN** 右侧选中区域出现编辑按钮；非默认项目同时出现删除按钮

### Requirement: 侧栏项目列表分页

侧栏项目列表 MUST 分页展示，避免一次铺开全部项目。「全部项目」MUST 固定在列表顶部，且不计入分页条目。分页控件 MUST 展示项目总数并允许翻页。创建或更新项目后，侧栏 MUST 翻到该项目所在页。

#### Scenario: 项目较多时分页

- **WHEN** 未删除项目超过一页容量
- **THEN** 侧栏当前页只展示一页项目，并提供翻页；「全部项目」仍固定在顶部

#### Scenario: 新建项目出现在当前可见页

- **WHEN** 用户创建新项目且该项目不在当前页
- **THEN** 侧栏翻到包含该项目的页，用户能在侧栏看到它

### Requirement: 删除实验项目

拥有训练中心菜单的会话 MUST 能删除非 Seed 项目。删除 MUST 使用`DELETE`软删除项目行，不得再用归档标记隐藏。`default` Seed 项目 MUST 拒绝删除并返回中文错误。删除成功后该项目 MUST 不再出现在侧栏；其下`Run` MUST 改挂到`default`项目，不得级联删除实验记录。删除后同名项目可再次创建。

#### Scenario: 删除后侧栏不再列出

- **WHEN** 用户删除项目`slm-7b-pretrain`且当前选中该项
- **THEN** 侧栏回到「全部项目」，该项目不再出现；其下`Run`出现在「默认项目」

#### Scenario: 默认项目不可删除

- **WHEN** 用户对 Seed「默认项目」确认删除
- **THEN** 接口失败，中文说明默认项目不可删除，侧栏仍保留该项

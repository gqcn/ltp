## MODIFIED Requirements

### Requirement: 管理员可以分页筛选平台用户

系统 MUST 列出从`LDAP`加入的平台用户，支持关键词（姓名/账号/邮箱/部门）、角色、启用状态与所属团队筛选，并在数据库侧分页。`teamId`省略或为`0`时 MUST 不按团队过滤；`teamId`大于`0`时 MUST 只返回该团队成员，一人多团队时命中所选团队即可。列表 MUST 批量投影角色名称、所属团队名称和最近登录时间，禁止对当前页循环查询。本地管理员账号 MUST NOT 出现在该列表中。

#### Scenario: 按角色筛选

- **WHEN** 管理员筛选角色为算法工程师
- **THEN** 返回的用户均具有该角色，且每条包含团队名称投影

#### Scenario: 按团队筛选

- **WHEN** 管理员在用户管理选择团队「SLM预训练」
- **THEN** 列表只出现该团队成员，未加入该团队的用户不出现；选择「全部团队」时不按团队收窄

#### Scenario: 本地管理员不在列表

- **WHEN** 管理员打开用户列表
- **THEN** 结果中不包含`admin`

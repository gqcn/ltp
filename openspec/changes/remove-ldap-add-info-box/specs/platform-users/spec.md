## MODIFIED Requirements

### Requirement: 管理员可以从 LDAP 添加平台用户

系统 MUST 允许勾选目录中尚未加入的账号，指定统一角色后批量加入。已在列表中的账号 MUST 跳过且不报错中断整批。新用户默认启用，密码留空，登录走`LDAP bind`。添加弹窗 MUST NOT 展示`LDAP`连接信息（协议、主机端口、`Base DN`、最近测试状态）；这些信息只在系统配置中维护。

#### Scenario: 添加尚未加入的目录用户

- **WHEN** 管理员勾选一名未在平台中的目录用户并指定角色后提交
- **THEN** 该用户出现在平台用户列表中，状态为启用，角色为所选角色

#### Scenario: 已加入的用户不会重复创建

- **WHEN** 管理员提交的账号已在平台用户列表中
- **THEN** 系统跳过该账号，不创建重复行

#### Scenario: 添加弹窗不展示连接信息

- **WHEN** 管理员打开「从 LDAP 添加用户」弹窗
- **THEN** 弹窗不出现协议、主机端口、`Base DN`或最近测试状态，仍可检索目录并勾选用户

## MODIFIED Requirements

### Requirement: 团队详情展示关联队列

队列模块启用后，团队详情 MUST 展示已关联队列列表（显示名、标识、数据中心、状态），数据由队列服务按团队 ID 批量投影。无关联时 MUST 展示空态而不是隐藏整块区域或报错。本迭代不在团队页提供「管理队列」写入入口，队列与团队的绑定在队列管理中维护。

#### Scenario: 已绑定队列的团队可见队列

- **WHEN** 管理员打开已关联`lab-default`的团队详情
- **THEN** 页面展示该队列显示名与标识，不再完全隐藏关联队列区域

#### Scenario: 未绑定队列的团队看到空态

- **WHEN** 管理员打开没有任何队列的团队详情
- **THEN** 关联队列区域展示空态文案，页面其余成员信息仍可用

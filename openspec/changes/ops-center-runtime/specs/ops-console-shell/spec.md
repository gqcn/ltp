## MODIFIED Requirements

### Requirement: 控制台只展示已启用模块

登录后壳层 MUST 包含可折叠侧栏、顶栏面包屑、主题切换与当前用户菜单。侧栏 MUST 只显示「角色菜单 ∩ 已启用模块」。本迭代已启用运维中心的数据中心、集群管理、节点管理、队列管理、告警中心，以及平台中心的用户/团队/角色/系统配置；训练中心与集群概览 MUST 完全隐藏。无任何可访问已启用模块时 MUST 展示空态页，而不是空白侧栏报错。运维中心页面 MUST 提供工作集群选择（至少存在一个接入集群时）。

#### Scenario: 管理员侧栏含运维集群能力

- **WHEN** 管理员查看侧栏
- **THEN** 可见数据中心、集群管理、节点管理、队列管理、告警中心与平台中心入口，不出现集群概览或任务列表

#### Scenario: 算法工程师看到空态

- **WHEN** `algo`用户登录后查看控制台
- **THEN** 页面展示无可用模块的空态，侧栏不出现训练或平台入口

## ADDED Requirements

### Requirement: 告警菜单可展示未完成数量

当告警模块启用且当前用户可见运维中心时，侧栏告警中心 MUST 展示未完成告警数量角标；数量为 0 时仍显示菜单，角标可为 0 或隐藏，但不得出现占位错误。

#### Scenario: 存在待处理告警时显示角标

- **WHEN** 告警中心存在待处理或跟进中的告警，管理员查看侧栏
- **THEN** 告警中心菜单可见数量角标

### Requirement: 表单校验失败使用中文并聚焦无效输入

控制台所有表单提交的客户端校验失败 MUST 返回准确中文错误，不得展示浏览器或 GoFrame 默认英文提示（例如 `Please fill out this field`、`The DisplayName field is required`）。错误 MUST 标注在对应输入域旁，并自动聚焦、滚入首个无效输入，使用户能立即定位。服务端兜底校验文案同样 MUST 为中文。

#### Scenario: 空表单提交聚焦首个必填项

- **WHEN** 用户打开新建数据中心、接入集群、新建队列、新建团队或登录表单后不填必填项并提交
- **THEN** 页面以中文提示具体缺项（例如「请填写显示名称」），对应输入域呈现错误态，焦点落在文档顺序中第一个无效输入，且不出现英文校验句

#### Scenario: 非法标识提示并聚焦该字段

- **WHEN** 用户在新建数据中心时填写不符合规范的标识并提交
- **THEN** 「数据中心标识」旁展示中文格式说明，焦点回到该输入域

### Requirement: 表单文本默认长度

控制台写表单在没有字段特例时，单行文本 MUST 最长 64 个字符，多行文本 MUST 最长 256 个字符。`DNS-1123`标识、展示色 hex、角色名称、`Kubeconfig` YAML 等已有特例的字段 MUST 保持原限制，不得被默认长度覆盖。超限时 MUST 在对应输入域旁展示中文「最长 N 个字符」并聚焦该域。

#### Scenario: 单行超过 64 个字符

- **WHEN** 用户在新建数据中心的显示名称中填入超过 64 个字符并提交
- **THEN** 该字段旁展示「最长 64 个字符」，焦点回到显示名称

#### Scenario: 多行超过 256 个字符

- **WHEN** 用户在新建数据中心的说明中填入超过 256 个字符并提交
- **THEN** 该字段旁展示「最长 256 个字符」，焦点回到说明

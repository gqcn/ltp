## MODIFIED Requirements

### Requirement: 数据中心列表展示真实关联计数

数据中心列表每行 MUST 展示关联节点数、队列数与集群数。节点数 MUST 按各已接入集群节点标签`maip.io/datacenter`聚合；队列数 MUST 按业务队列表的数据中心标识统计；集群数 MUST 统计至少含一台该数据中心节点的接入集群。计数 MUST 批量装配，禁止按数据中心循环查询。离线集群对该项贡献 0，不得使列表失败。无任何接入集群时三项均为 0。

#### Scenario: 节点打标后计数增加

- **WHEN** 某启用数据中心下存在 2 台节点和 1 条队列
- **THEN** 该数据中心列表行显示 2 节点、1 队列，且所属集群计数至少为 1

### Requirement: 存在关联时禁止删除数据中心

删除数据中心前 MUST 检查关联节点、队列与集群计数。任一项大于 0 时 MUST 拒绝删除并说明关联数量，不得改挂到其他数据中心。控制台删除按钮 MUST 对齐`prototype.v4`：有关联时弹出无法删除说明且不提供确认删除；无关联时二次确认后删除。

#### Scenario: 仍有队列时不能删除

- **WHEN** 运维删除仍关联队列的数据中心
- **THEN** 接口返回业务错误，数据中心仍然存在

#### Scenario: 无关联时二次确认后删除

- **WHEN** 运维点击无节点、队列或集群引用的数据中心删除并确认
- **THEN** 列表不再展示该记录

#### Scenario: 有关联时弹窗拦截且不可确认删除

- **WHEN** 运维点击仍关联节点、队列或集群的数据中心删除
- **THEN** 控制台展示无法删除说明与关联数量，不提供确认删除按钮，数据中心仍然存在

## REMOVED Requirements

### Requirement: 管理员可以启用或停用数据中心

**Reason**：数据中心只作为节点标签、队列和集群的关联锚点，不再用启停控制是否可被引用。不需要的数据中心应删除。

**Migration**：取消`PUT /datacenters/{id}/status`；控制台去掉启停按钮、状态列与启停筛选；存量`enabled=false`记录更新为可用；节点分配与新建队列不得因数据中心停用被拒绝。

#### Scenario: 列表没有停用按钮

- **WHEN** 运维打开数据中心列表
- **THEN** 操作列只有编辑和删除，没有停用或启用按钮

### Requirement: 控制台展示数据中心顶部统计与搜索框

**Reason**：数据中心数量少，列表本身已足够浏览，顶部统计与搜索增加干扰。

**Migration**：控制台去掉统计板块与搜索框；列表仍分页。后端列表接口可保留关键词与汇总字段，但不驱动页面展示。

#### Scenario: 打开列表不出现统计与搜索

- **WHEN** 运维打开数据中心管理
- **THEN** 页面没有「数据中心总数」统计卡，也没有搜索框

## ADDED Requirements

### Requirement: 列表数据中心列展示简称

任务列表、我的队列、队列管理、节点管理、团队已关联队列中，数据中心列 MUST 展示数据中心简称，MUST NOT 把全称或英文标识作为主文案。全称与标识可在悬停提示中保留。无简称时 MAY 回退显示名称；登记表中找不到该标识时，MAY 回退显示标识。

#### Scenario: 任务列表显示简称

- **WHEN** 任务的数据中心标识为`cq-lj`、名称为「重庆两江」、简称为「两江」
- **THEN** 任务列表该列展示「两江」，不把「重庆两江」或`cq-lj`作为徽章主文案

#### Scenario: 我的队列显示简称

- **WHEN** 算法工程师打开我的队列，某队列绑定数据中心简称为「两江」
- **THEN** 数据中心列展示「两江」

#### Scenario: 未登记标识回退

- **WHEN** 列表行的数据中心标识在登记表中不存在
- **THEN** 该列展示该标识本身，页面不报错

## MODIFIED Requirements

### Requirement: 侧栏只渲染角色菜单与已启用模块的交集

系统 MUST 按会话中的菜单分区与当前已启用模块的交集渲染侧栏。本迭代已启用`training`、`ops`与`platform`。未授权分区 MUST 隐藏而不是置灰。平台中心入口仅管理员可见。实验分析即使训练中心已启用也 MUST 完全隐藏。

#### Scenario: 管理员看到训练、运维与平台中心

- **WHEN** 本地管理员登录
- **THEN** 侧栏包含任务列表以及数据中心、用户管理，不包含实验分析

#### Scenario: SRE 看到训练中心与运维中心

- **WHEN** 角色为`sre`的用户登录
- **THEN** 侧栏包含任务列表与数据中心，不包含用户管理

#### Scenario: 算法工程师只看到训练中心

- **WHEN** 角色为`algo`的用户登录
- **THEN** 侧栏出现训练中心四菜单，不出现运维中心或平台中心入口

### Requirement: 落地页与 API 拒绝未授权访问

登录后 MUST 进入当前用户可访问的第一个已启用模块：同时拥有运维菜单时仍进入数据中心；仅有训练菜单时进入任务列表；若没有可访问模块，MUST 进入空态页。受保护 API 的`permission`标签 MUST 被执行：无训练菜单的用户不得调用训练接口；无运维菜单的用户不得调用数据中心接口；非管理员不得调用平台中心接口。

#### Scenario: 算法工程师进入任务列表

- **WHEN** `algo`用户登录成功
- **THEN** 系统进入任务列表，而不是空态页

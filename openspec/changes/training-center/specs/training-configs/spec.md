## ADDED Requirements

### Requirement: 用户可创建配置集并保存草稿或发布不可变版本

拥有训练中心菜单的会话 MUST 能创建配置集。必填：显示名称、所属团队、可见性（团队共享 / 仅自己可见）、框架（`megatron` / `nemo` / `accelerate` / `custom`）。同一团队下显示名称 MUST 唯一。单个配置文件 MUST 不超过 50 KB，路径仅允许字母数字、`.`、`_`、`-`与`/`。保存草稿 MUST 不要求版本说明；发布 MUST 填写版本说明且至少有一个文件。发布时若`baseVersion`与最新版本不一致 MUST 拒绝并提示重新加载。发布成功后草稿清除，版本号从 1 递增且历史版本不可改。非管理员 MUST 只能把配置集放到自己所属团队。

#### Scenario: 保存草稿后列表出现个人草稿标记

- **WHEN** 用户填写显示名称与团队后保存草稿
- **THEN** 配置列表该行可见个人草稿标记，尚未产生版本号

#### Scenario: 无版本说明不能发布

- **WHEN** 用户在发布页签不填版本说明并点发布
- **THEN** 版本说明输入域旁展示中文错误，不新增版本

#### Scenario: 超限文件拒绝保存

- **WHEN** 用户编辑的某个文件超过 50 KB 并保存草稿
- **THEN** 接口拒绝，草稿不被覆盖

### Requirement: 配置列表与详情按可见性过滤

列表 MUST 支持按关键词、团队、范围（我创建的 / 团队共享 / 仅自己可见 / 有个人草稿）、状态、框架筛选并分页。`private`配置 MUST 仅创建人与管理员可见。归档后 MUST 仍可在列表用状态筛选看到，但新建任务的配置下拉 MUST 不再出现。详情 MUST 展示最新版文件与版本历史，历史版本可只读查看。

#### Scenario: 私有配置对其他团队成员隐藏

- **WHEN** 用户 A 创建仅自己可见的配置集，用户 B 同团队但不是创建人
- **THEN** B 的配置列表不出现该配置集

#### Scenario: 归档配置不可再挂到新任务

- **WHEN** 某配置集已归档
- **THEN** 新建任务的配置集下拉不包含它，已挂载该版本的历史任务详情仍可展开快照

## ADDED Requirements

### Requirement: 管理员用标签式交互选择数据中心展示色

创建或编辑数据中心时，展示色 MUST 提供与 GitHub Issue 标签类似的交互：点击颜色图标立即切换到下一个常用色；点击颜色输入框 MUST 弹出常用色板；输入框 MUST 允许手填`#RRGGBB`。常用色板 MUST 使用 GitHub 标签默认 16 色。选择色板中的颜色 MUST 把该值写入输入框。不得再使用会打开系统取色器的原生`type="color"`控件作为主交互。

#### Scenario: 点击颜色图标切换常用色

- **WHEN** 管理员打开新建数据中心弹窗并点击展示色图标
- **THEN** 颜色输入框的值变为色板中的下一项常用色，且不打开系统取色器

#### Scenario: 点击输入框弹出常用色板并选用

- **WHEN** 管理员点击展示色输入框，再点选色板中的某一常用色
- **THEN** 输入框值为该常用色的`#RRGGBB`

#### Scenario: 手填颜色编码

- **WHEN** 管理员在展示色输入框输入合法`#RRGGBB`并保存
- **THEN** 该数据中心使用手填的颜色

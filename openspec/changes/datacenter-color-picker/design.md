## Context

创建/编辑弹窗里「展示色」是原生颜色选择器加 hex 文本框。原生选择器在各系统外观不一，也不提供常用色。GitHub Issue 标签编辑器用色块刷新切换 + hex 输入 + 16 色预设板。

## Goals / Non-Goals

**Goals:**

- 点击色块图标立即换成另一个常用色，不打开系统取色器。
- 点击或聚焦 hex 输入框展开常用色板，点色块即写入。
- 输入框始终可手填`#RRGGBB`。
- 非法值仍由后端`normalizeColor`回落到`#3b82f6`。

**Non-Goals:**

- 不做自由取色盘、吸管、透明度。
- 不改后端校验与存储格式。
- 不把选色器抽成全站通用组件以外的设计系统包。

## Decisions

1. **预设色用 GitHub 标签默认 16 色**
   - 与参考交互一致，两行八列。
   - 新建默认仍是`#3b82f6`（现有表单默认）。首次点图标时当前值不在板上，切到板首色`#b60205`。

2. **点图标按色板顺序切换，而不是随机**
   - GitHub 刷新偏随机，但顺序切换可测、可预期，符合「自动切换」。
   - 当前色在板中则取下一个并循环；不在则取第一项。

3. **色板跟在输入框下方文档流里展开**
   - 弹窗`overflow: hidden`，绝对定位下拉会被裁切。
   - 点色板项后收起；Esc 或点弹窗其它处收起。

4. **去掉`<input type="color">`**
   - 避免再唤起系统取色器，和「点图标切换」冲突。

## Risks / Trade-offs

- [弹窗内点击色板导致输入失焦、点选失败] → 色板`mousedown`阻止默认失焦。
- [浅色板上刷新图标看不清] → 按亮度切换图标为深色或浅色。

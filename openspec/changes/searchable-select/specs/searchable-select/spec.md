## ADDED Requirements

### Requirement: 选择类下拉可按关键字过滤

控制台中用于选值的下拉 MUST 使用共享可搜索选择器，不得继续使用不可输入过滤的原生`select`。打开后 MUST 能输入关键字，并按选项可见文案过滤。无匹配时 MUST 展示中文「无匹配选项」，且 MUST NOT 出现英文空态。禁用的只读选择器 MUST 不可打开、不可输入。

#### Scenario: 按关键字缩小团队选项

- **WHEN** 管理员在用户管理打开团队筛选并输入某团队名称中的连续字
- **THEN** 列表只保留文案包含该关键字的团队，选择后列表按该团队筛选

#### Scenario: 无匹配时中文提示

- **WHEN** 用户在任意选择类下拉中输入与所有选项都不匹配的关键字
- **THEN** 下拉展示「无匹配选项」，不出现英文`No options`之类提示

#### Scenario: 禁用选择器不可搜索

- **WHEN** 新建训练任务中卡型号由已选队列决定因而禁用
- **THEN** 该选择器不可打开、不能输入关键字

### Requirement: 列表筛选下拉宽度舒适且选项可读

任务、配置、实验、节点、队列、用户等列表页顶部的筛选选择器闭合态 MUST 使用统一的舒适宽度，默认筛选项文案 MUST 完整显示、不得贴紧箭头。打开后菜单 MUST 至少与控件等宽，并可随较长选项变宽；选项 MUST 单行展示，不得把`SchedulingDisabled`或长团队名称裁切到不可读。

#### Scenario: 列表页筛选同宽且默认文案完整

- **WHEN** 管理员打开任务列表、配置管理、实验分析、节点管理、队列管理或用户管理
- **THEN** 顶部筛选下拉宽度一致，且「全部优先级」「全部数据中心」等默认文案完整可见

#### Scenario: 打开后长选项单行可读

- **WHEN** 管理员打开节点状态筛选或任务团队筛选
- **THEN** `SchedulingDisabled`与长团队名称在菜单中单行完整显示

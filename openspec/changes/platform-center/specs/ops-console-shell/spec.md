## MODIFIED Requirements

### Requirement: 未登录用户看到登录页

未登录访问控制台 MUST 进入登录页。登录页 MUST 提供`LDAP`用户与平台管理员两个入口、主题切换，以及与原型一致的产品名称「MAIP-大模型训练平台」。`LDAP`入口 MUST 可提交并走后端认证，不得仅在前端提示「后续接入」。

#### Scenario: 打开根路径进入登录

- **WHEN** 未登录用户打开应用根路径
- **THEN** 页面默认展示`LDAP`登录表单，并可切换到平台管理员入口，不展示控制台侧栏

#### Scenario: 管理员登录成功进入控制台

- **WHEN** 管理员登录成功
- **THEN** 系统进入控制台壳层，并打开数据中心管理页

#### Scenario: LDAP 用户登录成功进入可访问页面

- **WHEN** `sre`用户`LDAP`登录成功
- **THEN** 系统进入控制台壳层并打开数据中心管理页

### Requirement: 控制台只展示已启用模块

登录后壳层 MUST 包含可折叠侧栏、顶栏面包屑、主题切换与当前用户菜单。侧栏 MUST 只显示「角色菜单 ∩ 已启用模块」。本迭代已启用运维中心的数据中心与平台中心的用户/团队/角色/系统配置；训练中心、集群概览、集群管理、节点管理、队列管理、告警中心 MUST 完全隐藏。无任何可访问已启用模块时 MUST 展示空态页，而不是空白侧栏报错。

#### Scenario: 管理员侧栏含平台中心

- **WHEN** 管理员查看侧栏
- **THEN** 可见数据中心、用户管理、团队管理、角色管理与系统配置，不出现任务列表

#### Scenario: 算法工程师看到空态

- **WHEN** `algo`用户登录后查看控制台
- **THEN** 页面展示无可用模块的空态，侧栏不出现训练或平台入口

### Requirement: 用户可以切换浅色和深色主题

主题 MUST 在浅色与深色之间切换，并持久化到浏览器本地存储，刷新后保持上次选择。

#### Scenario: 刷新后保持主题

- **WHEN** 用户切换到浅色主题并刷新页面
- **THEN** 页面仍以浅色主题渲染

### Requirement: 用户可以从壳层退出

用户菜单 MUST 提供退出登录。退出后 MUST 回到登录页，且不能继续看到受保护业务数据。

#### Scenario: 从侧栏退出

- **WHEN** 已登录用户点击退出登录
- **THEN** 系统回到登录页，直接访问数据中心路由会被带回登录页

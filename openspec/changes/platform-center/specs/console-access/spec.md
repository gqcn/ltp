## ADDED Requirements

### Requirement: 侧栏只渲染角色菜单与已启用模块的交集

系统 MUST 按会话中的菜单分区与当前已启用模块的交集渲染侧栏。本迭代已启用`ops`与`platform`；`training`即使出现在角色菜单中也 MUST 完全隐藏。未授权分区 MUST 隐藏而不是置灰。平台中心入口仅管理员可见。

#### Scenario: 管理员看到运维与平台中心

- **WHEN** 本地管理员登录
- **THEN** 侧栏包含数据中心以及用户、团队、角色、系统配置，不包含任务列表

#### Scenario: SRE 只看到运维中心

- **WHEN** 角色为`sre`的用户登录
- **THEN** 侧栏包含数据中心，不包含用户管理与任务列表

#### Scenario: 算法工程师看不到未启用的训练中心

- **WHEN** 角色为`algo`的用户登录
- **THEN** 侧栏不出现训练中心、运维中心或平台中心入口

### Requirement: 落地页与 API 拒绝未授权访问

登录后 MUST 进入当前用户可访问的第一个已启用模块；若没有可访问模块，MUST 进入空态页。受保护 API 的`permission`标签 MUST 被执行：无运维菜单的用户不得调用数据中心接口；非管理员不得调用平台中心接口。

#### Scenario: 算法工程师进入空态页

- **WHEN** `algo`用户登录成功
- **THEN** 系统进入空态页，说明当前没有可访问的已启用模块

#### Scenario: 算法工程师直接打开数据中心被拒绝

- **WHEN** `algo`用户的会话请求数据中心列表
- **THEN** 系统拒绝并返回无权限错误，不返回业务数据

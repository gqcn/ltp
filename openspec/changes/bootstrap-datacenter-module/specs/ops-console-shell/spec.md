## ADDED Requirements

### Requirement: 未登录用户看到登录页

未登录访问控制台 MUST 进入登录页。登录页 MUST 提供平台管理员账号密码表单、主题切换，以及与原型一致的产品名称「MAIP-大模型训练平台」。本迭代 MUST NOT 提供可用的`LDAP`登录提交。

#### Scenario: 打开根路径进入登录

- **WHEN** 未登录用户打开应用根路径
- **THEN** 页面展示平台管理员登录表单，而不展示控制台侧栏

#### Scenario: 登录成功进入控制台

- **WHEN** 管理员登录成功
- **THEN** 系统进入控制台壳层，并打开数据中心管理页

### Requirement: 控制台只展示已启用模块

登录后壳层 MUST 包含可折叠侧栏、顶栏面包屑、主题切换与当前用户菜单。本迭代侧栏 MUST 只显示「运维中心 / 数据中心」；训练中心、集群概览、集群管理、节点管理、队列管理、告警中心、平台中心入口 MUST 完全隐藏，而不是置灰。

#### Scenario: 侧栏不含未实现模块

- **WHEN** 管理员查看侧栏
- **THEN** 可见菜单仅为数据中心，不出现任务列表、新建任务、用户管理等未启用入口

### Requirement: 用户可以切换浅色和深色主题

主题 MUST 在浅色与深色之间切换，并持久化到浏览器本地存储，刷新后保持上次选择。

#### Scenario: 刷新后保持主题

- **WHEN** 用户切换到浅色主题并刷新页面
- **THEN** 页面仍以浅色主题渲染

### Requirement: 用户可以从壳层退出

用户菜单 MUST 提供退出登录。退出后 MUST 回到登录页，且不能继续看到数据中心数据。

#### Scenario: 从侧栏退出

- **WHEN** 已登录用户点击退出登录
- **THEN** 系统回到登录页，直接访问数据中心路由会被带回登录页
